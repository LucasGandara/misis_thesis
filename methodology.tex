\section{Methodology}
We present a solution integrating Transfer Learning using Learning from Demonstration on a Twin Delayed Deep Deterministic Policy Gradient expert agent within a mobile base, specifically applied to a line-changing paradigm. The validation was conducted through comparative experiments between the expert TD3 agent and an agent utilizing Transfer Learning. The evaluation examined transfer ratio, mastery, and pedagogy metrics.
